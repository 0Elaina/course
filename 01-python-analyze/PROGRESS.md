## 薄弱点
| 知识点 | 问题描述 |
|--------|---------|
| range 与普通迭代器的操作边界 | 需谨记 range 支持下标/len但不支持 next()；迭代器单向惰性取值，不支持下标访问（已通关） |
| 列表推导式 if 位置规则 | 过滤删减放末尾无 else；二选一映射三元放开头必须带 else（已变式题通关巩固） |
| 星号解包的产出类型与适用范围 | 任意可迭代对象（含字符串）均可解包；带 `*` 变量统一强制打包为 `list`（已强化通关） |
| 不可变对象作为实参的重绑定 | 函数内部对形参重新赋值（如 x = x + y）只改变局部标签指向，不影响外部实参原值（已闭环通关） |
| 列表的原地修改 vs 赋值拼接 | lst.append()/extend() 原地修改原对象影响外部实参；lst = lst + [...] 产生新对象局部重绑定，不影响实参（已变式题通关巩固） |
| 生成器函数惰性启动时机 | 调用生成器函数（g = gen()）时不执行任何函数体语句；首次执行 next(g) 时才启动函数并运行至首个 yield 挂起（已随身听模型通关巩固） |
