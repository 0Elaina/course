## ⚡ 30秒高频对比速查卡 (CheatSheet)

### 1. 核心容器特性对比
| 数据结构 | 是否有序 | 是否可变 | 元素去重 | 访问方式 | 典型用途 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **列表 `list`** | 有序 | 可变 | 否 | 双向整数下标、切片 | 动态序列、按序排列数据 |
| **元组 `tuple`** | 有序 | 不可变 | 否 | 双向整数下标、切片 | 固定只读配置、字典键、函数多返回值 |
| **字典 `dict`** | 有序 (3.7+) | 可变 | 键唯一 | 通过键访问（`d[k]` 或 `d.get(k)`） | 键值映射、关联数据表、频次统计 |
| **集合 `set`** | 无序 | 可变 | 是 (去重) | 迭代遍历、数学集合运算 | 快速去重、常数级关系判断（交并差） |

### 2. 函数形参分类与语法约束
| 参数类别 | 声明语法示例 | 实参打包形态 | 核心约束与位置规则 |
| :--- | :--- | :--- | :--- |
| **位置形参** | `def f(a, b):` | 直接一对一绑定 | 必须严格按位置传入 |
| **默认值形参** | `def f(a, b=10):` | 缺省时采用默认值 | **必须排在所有无默认值形参之后** |
| **可变位置参数** | `def f(*args):` | 打包为 **`tuple`** | 单函数最多 1 个，排在位置与默认参数之后 |
| **可变关键字参数** | `def f(**kwargs):` | 打包为 **`dict`** | 单函数最多 1 个，**必须永远排在形参列表最后** |

## 🛡️ 全局高频易错避坑表

| 经典报错 / 陷阱场景 | 典型错误代码 | 根因剖析 | 正确修正 |
| :--- | :--- | :--- | :--- |
| **误以为列表方法有返回值** | `lst = lst.append(1)`<br>`lst = lst.sort()` | `append`、`sort`、`reverse`、`extend`、`clear` 均是原地操作，返回值为 `None`。 | 去掉赋值，直接写 `lst.append(1)` 或用 `sorted(lst)`。 |
| **列表通过新下标越界追加** | `lst = [1, 2]; lst[2] = 3` | 列表不会因指定新下标而自动扩容，只报 `IndexError`。 | 使用 `lst.append(3)` 或切片插入。 |
| **推导式过滤末尾误加 else** | `[x for x in s if x > 0 else 0]` | 过滤型 `if` 在末尾，属于门卫安检机制，语法禁止写 `else`。 | 二选一映射改写为头部三元：`[x if x > 0 else 0 for x in s]`。 |
| **乘法重复产生嵌套浅拷贝** | `m = [[0]*3]*3; m[0][0] = 1` | 外层 `*` 复制的是同一内层列表的引用，导致修改一处整列变动。 | 改用推导式独立创建：`[[0]*3 for _ in range(3)]`。 |
| **跨步切片赋值长度不匹配** | `a = [1,2,3,4]; a[::2] = [10]` | 跨步切片坑位固定，右侧元素数量必须严格 1:1 对齐。 | 元素个数需与切片坑位数精确一致。 |
| **切片赋值非可迭代对象** | `a[1:3] = 99` | 切片赋值右侧必须是可迭代序列。 | 改为可迭代对象：`a[1:3] = [99]`。 |
| **字典转换只取键** | `list({'a': 1, 'b': 2})` | 字典直接放入 `list()` 时默认仅迭代其键。 | 需键值对用 `list(d.items())`。 |
| **浅拷贝嵌套修改串扰** | `y = x.copy(); y[1].append(4)` | 浅拷贝仅克隆第一层外壳，内层嵌套容器引用仍相同。 | 需完全隔离时使用 `copy.deepcopy(x)`。 |
| **可哈希性混入可变容器** | `d = {(1, [2]): 100}` | 元组自身可哈希的前提是内部**所有**元素均为不可变类型。 | 内部改用不可变类型：`d = {(1, (2,)): 100}`。 |
| **单元素元组漏写逗号** | `t = (1)` | 括号被识别为算术优先级符号，实际得到 `int`。 | 必须带逗号：`t = (1,)`。 |
| **圆括号推导式当作元组** | `t = (x for x in range(3))` | 实际生成的是生成器对象，非元组。 | 需显式类型转换：`tuple(x for x in range(3))`。 |
| **空集合写成花括号** | `s = {}` | `{}` 默认是空字典 `dict`。 | 空集合必须写为：`s = set()`。 |
| **集合删除元素不存在崩溃** | `s.remove('not_exist')` | 不存在时抛出 `KeyError`。 | 优先使用安全删除：`s.discard('not_exist')`。 |
| **星号解包结果误判类型** | `*rest, = (1, 2, 3)` | 误以为产出元组。PEP 3132 规定星号接收物统一为 `list`。 | 谨记带 `*` 变量类型一律为 `list`。 |
| **误以为字符串不能被解包** | `a, *b = "HELLO"` 以为报错 | 字符串是字符序列，属于可迭代对象，完全支持解包。 | `a` 为 `'H'`，`b` 为 `['E', 'L', 'L', 'O']`。 |
| **函数传参不可变对象误判被改** | `def f(x): x+=1`<br>`a=1; f(a)` | 不可变对象（int/str/tuple）赋值只是重绑定局部标签，外部实参不变。 | 需通过 `return` 送出新值。 |
| **列表形参原地修改 vs 赋值重绑定** | `def f(x, y):`<br>` x.append(1); y = y + [1]` | 原地修改方法（`append`）同步改变外部实参；加号赋值（`y = y + ...`）产生新列表仅重绑定局部变量，外部实参不变。 | 理解原地操作与重绑定的差异；防御性编程可传入 `lst.copy()`。 |
| **误以为函数多返回值是多对象** | `def f(): return 1, 2` | Python 仅支持返回单一对象，多返回值实质由逗号隐式打包为 **`tuple`**。 | 单变量接收为元组，或用多变量解包接收。 |
| **UnboundLocalError 作用域早崩** | `x=1`<br>`def f(): print(x); x=2` | 解释器静态扫描发现函数内有赋值，将 `x` 打上局部变量标签；首行读取未初始化局部变量崩。 | 若需改全局变量，首行声明 `global x`。 |
| **误以为生成器调用即执行** | `def f(): print(1); yield`<br>`g = f()` 以为打印 1 | 生成器函数被调用时**一行都不执行**（不按播放键不发声），只返回生成器对象；必须 `next(g)` 唤醒。 | 牢记生成器惰性启动模型，首次 `next(g)` 才执行至首个 `yield`。 |
