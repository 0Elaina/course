> [!TIP]
> **30秒速记卡**
> - **可变 vs 不可变传参**：不可变对象形参重绑定不影响实参；可变对象**原地修改**（`.append()`、`[0]=...`）会同步影响外部实参，**赋值重绑定**（`lst = lst + [...]`）产生新对象，不影响外部实参。
> - **实参传递形式**：
>   - **位置实参**：严格按顺序 1:1 对齐；
>   - **关键字实参**：按形参名显式指定（`key=val`），顺序无关。
>   - **语法铁律**：位置实参必须严格排在关键字实参前面！
> - **默认值参数**：有默认值的形参必须放在所有非默认值形参的后面。
> - **可变长度参数**：
>   - `*args`：将多余位置实参打包为**元组（tuple）**；
>   - `**kwargs`：将多余关键字实参打包为**字典（dict）**。
> - **形参定义顺序**：普通位置形参 $\rightarrow$ 默认值形参 $\rightarrow$ `*args` $\rightarrow$ `**kwargs`。

## 一、参数传递机制深度拆解

Python 参数传递本质是**传对象引用（Call-by-Object-Reference）**。

| 实参类型 | 函数内部操作 | 是否影响外部实参 | 底层根因 |
| :--- | :--- | :--- | :--- |
| **不可变对象** (`int`, `str`, `tuple`) | 重新赋值（如 `x = x + 1`） | ❌ 不影响 | 局部标签重绑定到新对象，外部原标签未动。 |
| **可变对象** (`list`, `dict`, `set`) | **原地修改**（如 `v.append(99)`, `d['k'] = v`） | ✅ **同步影响** | 局部标签与外部标签指向同一堆内存容器。 |
| **可变对象** (`list`, `dict`, `set`) | **赋值重绑定**（如 `v = v + [99]`） | ❌ 不影响 | `+` 产生全新容器，赋值仅将局部便签重定向。 |

> [!TIP]
> **防御性编程**：若不希望可变对象在函数内被修改影响外部，应传入其副本：`modify(a.copy())` 或 `modify(a[:])`。

## 二、实参形式与调用规则

### 1. 位置实参 vs 关键字实参
```python
def describe_pet(animal_type, pet_name):
    print(f"I have a {animal_type} named {pet_name}.")

# 1. 位置实参：按先后顺序对齐
describe_pet('cat', 'harry')

# 2. 关键字实参：按名称匹配，顺序无关
describe_pet(pet_name='harry', animal_type='cat')

# 3. 混用规则：位置实参必须在关键字实参之前
describe_pet('cat', pet_name='harry')  # ✅ 合法
# describe_pet(animal_type='cat', 'harry') # ❌ SyntaxError
```

### 2. 默认参数（可选参数）
- **声明规则**：必须放在无默认值参数之后。
- **定义示例**：
  ```python
  def describe_pet(pet_name, animal_type='dog'):
      pass
  ```
- **避坑警示**：避免将**可变对象（如 `[]`、`{}`）** 作为形参默认值，因为默认参数在函数定义时仅初始化一次，会被多次调用共享。安全做法是使用 `None`：
  ```python
  def append_to(item, target=None):
      if target is None:
          target = []
      target.append(item)
      return target
  ```

## 三、可变长度参数（*args 与 **kwargs）

| 形式 | 接收对象 | 打包后容器类型 | 数量限制 |
| :--- | :--- | :--- | :--- |
| `*args` | 多余的位置实参 | **元组 `tuple`** | 单个函数最多 1 个 |
| `**kwargs` | 多余的关键字实参 | **字典 `dict`** | 单个函数最多 1 个，且必须在末尾 |

```python
def make_pizza(size, *toppings):
    print(f"尺寸: {size}, 配料: {toppings}")  # toppings 为 tuple

make_pizza(12, 'mushrooms', 'cheese')
# 尺寸: 12, 配料: ('mushrooms', 'cheese')

def build_profile(first, last, **user_info):
    print(f"姓名: {first} {last}, 额外信息: {user_info}")  # user_info 为 dict

build_profile('Albert', 'Einstein', city='Princeton', field='Physics')
# 姓名: Albert Einstein, 额外信息: {'city': 'Princeton', 'field': 'Physics'}
```

## 四、形参定义的标准顺序法则

在同一个函数定义中，混合参数的声明顺序必须严格如下：

$$\boxed{\text{位置形参}} \longrightarrow \boxed{\text{默认值形参}} \longrightarrow \boxed{\text{*args (元组)}} \longrightarrow \boxed{\text{**kwargs (字典)}}$$

```python
def example_func(a, b=10, *args, **kwargs):
    pass
```
