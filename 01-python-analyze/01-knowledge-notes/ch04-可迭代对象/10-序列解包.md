> [!TIP]
> **30秒速记卡**
> - **核心本质**：只要是**可迭代对象（列表、元组、字符串、集合、字典、生成器）**，统统支持序列解包！
> - **基本解包**：左侧变量数必须与右侧元素数严格相等，否则抛出 `ValueError`。
> - **星号解包两大铁律**：
>   1. **类型铁律**：无论原始对象是什么，带 `*` 接收的剩余变量**永远统一打包为【列表 `list`】**！
>   2. **唯一性铁律**：同一层解包中**只能有一个带 `*` 的变量**。
> - **字典解包**：直接解包 `a, b = d` 提取的是**键（Key）**；字典合并使用 `**d`。

## 一、序列解包核心语法分类

| 解包方式 | 示范代码 | 变量接收结果 | 常见报错风险 |
| :--- | :--- | :--- | :--- |
| **基础精确解包** | `a, b = 1, 2`<br>`x, y, z = "CAT"` | `a=1, b=2`<br>`x='C', y='A', z='T'` | 数量不匹抛 `ValueError` |
| **首尾截取解包** | `head, *rest = (1, 2, 3, 4)` | `head=1`, `rest=[2, 3, 4]` | 多个 `*` 抛 `SyntaxError` |
| **中间汇聚解包** | `a, *mid, b = "HELLO"` | `a='H'`, `b='O'`, `mid=['E', 'L', 'L']` | - |
| **变量原地对调** | `a, b = b, a` | 交换两变量绑定的对象指针 | 无（无需中间变量 `temp`） |
| **字典默认解包** | `k1, k2 = {'x': 1, 'y': 2}` | `k1='x', k2='y'`（默认解包键） | 误以为拿到值 |

## 二、关键考点与机制深度剖析

### 1. 深度破局：解包对象的广泛性与星号返回值类型
```python
# 案例 1：字符串是字符序列，完全支持解包
s = "CAT"
first, *rest = s
print(first)       # 'C'
print(type(rest))  # <class 'list'> -> 统一强制转为 list！
print(rest)        # ['A', 'T']

# 案例 2：元组解包，星号接收依然是 list
t = (1, 2, 3, 4)
a, *b, c = t
print(type(b))     # <class 'list'>
print(b)           # [2, 3]
```

### 2. 双星号与字典合并应用
```python
defaults = {'theme': 'dark', 'font_size': 14}
user_cfg = {'font_size': 16, 'show_line': True}

# 使用 ** 解包快速合并字典（后方覆盖前方）
final_cfg = {**defaults, **user_cfg}
print(final_cfg)
# {'theme': 'dark', 'font_size': 16, 'show_line': True}
```

## 三、易错避坑表

| 经典误区 | 产生的报错 | 避坑指引 |
| :--- | :--- | :--- |
| `a, b = [1, 2, 3]` | `ValueError: too many values to unpack (expected 2)` | 数量不确定时，给接收多余元素的变量前加 `*`：`a, *b = [1, 2, 3]`。 |
| `*a, *b = [1, 2, 3]` | `SyntaxError: two starred expressions in assignment` | 同一层解包绝对不能出现两个 `*` 变量。 |
| 以为 `k, v = {'a': 1}` 能解包键和值 | `ValueError: not enough values to unpack (expected 2, got 1)` | 字典直接解包只产出 Key。若要同时解包键值对，必须写为：`for k, v in d.items():`。 |
