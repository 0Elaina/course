> [!TIP]
> **30秒速记卡**
> - **核心特性**：键值对（Key-Value）映射、基于哈希表实现、**$O(1)$ 常数级极速查找**、Python 3.7+ 保证插入有序。
> - **键的铁律**：**键唯一**（重复写键后面覆盖前面）；**键必须可哈希（不可变对象）**，列表、字典绝不能做键。
> - **安全取值**：`d[k]` 键不存在抛 `KeyError`；**`d.get(k, default)` 优雅容错返回默认值**。
> - **`setdefault(k, v)` 神技**：若存在返回原值（不动字典）；若不存在，**顺手写入 `k: v` 并返回 `v`**（查漏补缺）。
> - **字典推导式**：`{k_expr: v_expr for item in iter if cond}`，做键值互换时注意重复值覆盖问题。

## 一、字典核心机制与操作矩阵

### 1. 键（Key）与值（Value）的约束对比

| 项目 | 约束要求 | 合法示例 | 非法示例 |
| :--- | :--- | :--- | :--- |
| **键（Key）** | **必须可哈希（不可变）且绝对唯一** | `1`, `'name'`, `(1, 2)` | `[1, 2]`, `{'a': 1}`, `(1, [2])` |
| **值（Value）**| **无任何限制**（支持任意对象与深层嵌套） | 任意对象、函数、列表、字典等 | 无 |

### 2. 核心方法功能与返回值速查

| 方法名 | 核心行为 | 键不存在时的表现 | 是否改变原字典 |
| :--- | :--- | :--- | :--- |
| **`d[k]`** | 直接按键索取对应值 | 💥 抛出 `KeyError` | 否 |
| **`d.get(k, default)`** | 安全获取对应值 | 返回 `default`（默认为 `None`） | **否（纯只读查询）** |
| **`d.setdefault(k, def)`**| 查询并在缺失时落户 | **将 `k: def` 存入字典并返回 `def`** | **是（若缺失则修改）** |
| **`d.update(other)`** | 批量合并另一字典或键值序列 | 有则覆盖，无则追加 | 是 |
| **`d.pop(k, default)`** | 弹出指定键并返回值 | 若无 default 抛 `KeyError` | 是 |
| **`d.popitem()`** | 弹出最后插入的 `(k, v)` 元组 (LIFO) | 字典为空抛 `KeyError` | 是 |
| **`d.keys()` / `.values()` / `.items()`** | 动态视图（联动实时变化） | 返回对应类型的视图对象 | 否 |

## 二、关键机制图解与经典考点

### 1. 键的唯一性与字面量覆盖
```python
d = {'a': 1, 'b': 2, 'a': 99}
print(len(d))  # 2 (只有 'a' 和 'b' 两个键)
print(d['a'])  # 99 (后来的值覆盖前面的值)
```

### 2. 字典推导式与键值反转踩坑
```python
scores = {'Alice': 95, 'Bob': 80, 'Charlie': 95}

# 反向映射：分数为键，姓名为值
inv = {score: name for name, score in scores.items()}
print(inv)      # {95: 'Charlie', 80: 'Bob'} -> 'Alice' 被覆盖丢失！
print(len(inv)) # 2 (因 95 重复，键发生覆盖收缩)
```

## 三、易错避坑表

| 常见误区 | 产生后果 | 正确规范姿势 |
| :--- | :--- | :--- |
| `d = {[1, 2]: 'val'}` | 报 `TypeError: unhashable type: 'list'` | 列表可变不可哈希，必须换成元组 `d = {(1, 2): 'val'}`。 |
| 直接用 `d['unknown']` 读不确定字段 | 抛出 `KeyError` 导致生产事故 | 使用安全读取：`d.get('unknown', 默认值)`。 |
| 以为 `setdefault` 会覆盖已有值 | 原值未被更改，引发逻辑 Bug | `setdefault` 仅在键缺失时起效，若要强制覆盖请直接用 `d[k] = val`。 |
