> [!TIP]
> **30秒速记卡**
> - **聚合函数**：`len()` 求长；`max()`/`min()` 极值（支持 `key` 规则）；`sum(seq, start=0)` 求和（仅数值，初始默认 0）。
> - **排序对比**：`lst.sort()` 原地修改（返回 `None`）；`sorted(lst)` 不变原序列（返回新排好序的列表）。
> - **逆序对比**：`lst.reverse()` 原地逆序（返回 `None`）；`reversed(lst)` 返回反向迭代器（需用 `list()` 展开）。
> - **配对与枚举**：`zip(*iters)` 像拉链对齐打包（**短板截断原则**，以最短序列为准）；`enumerate(seq, start=0)` 同时输出下标与值。
> - **逻辑判定**：`all()` 全真才真（遇到假短路，`all([])` 为 True）；`any()` 任一真即真（遇到真短路，`any([])` 为 False）。

**标签**：`#Python` `#内置函数` `#高阶函数` `#sorted` `#zip` `#enumerate`

## 一、高频内置函数分类速查矩阵

| 函数名称 | 核心语法 | 典型应用 | 返回值类型 | 是否改变原列表 |
| :--- | :--- | :--- | :--- | :--- |
| **`len(s)`** | `len(lst)` | 获取元素个数 | `int` | 否 |
| **`max(s)` / `min(s)`** | `max(lst, key=func)` | 寻找最大/最小值，可指定比对依据 | 列表中的元素 | 否 |
| **`sum(s, start)`** | `sum(nums, 10)` | 数值累加（可指定累加初始值） | `int` / `float` | 否 |
| **`sorted(s)`** | `sorted(lst, key=..., reverse=True)` | 全新升序/降序排序 | **全新 `list`** | **否** |
| **`reversed(s)`** | `reversed(lst)` | 惰性反向迭代 | `list_reverseiterator` | **否** |
| **`enumerate(s)`**| `enumerate(lst, start=0)` | 遍历时同时追踪索引计数 | `enumerate` 迭代器 | 否 |
| **`zip(*iters)`** | `zip(list1, list2)` | 多序列按列对齐配对 | `zip` 迭代器 | 否 |
| **`all(s)`** | `all(lst)` | 判断是否全为真值（短路求值） | `bool` | 否 |
| **`any(s)`** | `any(lst)` | 判断是否存在真值（短路求值） | `bool` | 否 |

## 二、关键机制与考点深度剖析

### 1. `sort()` 与 `sorted()` 的终极对比
```python
words = ['banana', 'apple', 'pear']

# 1. 原地排序方法
res1 = words.sort()
print(res1)   # None (绝不要赋值！)
print(words)  # ['apple', 'banana', 'pear'] (原列表被修改)

# 2. 全局排序函数
words = ['banana', 'apple', 'pear']
res2 = sorted(words, key=len)
print(res2)   # ['pear', 'apple', 'banana'] (按字符串长度排出的新列表)
print(words)  # ['banana', 'apple', 'pear'] (原列表完好无损)
```

### 2. `zip()` 的短板截断效应
当被打包的多个序列长度不同时，以**最短序列耗尽**为终止条件：
```python
names = ['Alice', 'Bob', 'Charlie']
scores = [95, 88]
pairs = list(zip(names, scores))
print(pairs)  # [('Alice', 95), ('Bob', 88)] -> 'Charlie' 被截断丢弃！
```

### 3. `all()` 与 `any()` 在空序列上的特例
```python
print(all([]))  # True  (空集合无任何反例，故为真)
print(any([]))  # False (空集合无任何真例，故为假)
```

## 三、易错避坑表

| 常见误区 | 报错 / 异常表现 | 正确做法 |
| :--- | :--- | :--- |
| `s = sum(['a', 'b'])` | 报 `TypeError: unsupported operand type(s) for +` | 字符串拼接用 `''.join(['a', 'b'])`，`sum` 仅用于数值。 |
| `lst = sorted(lst.sort())` | 报 `TypeError: 'NoneType' object is not iterable` | `lst.sort()` 返回 None，不能传给 `sorted`。 |
| `z = zip(a, b); print(list(z)); print(list(z))` | 第二次输出变成空列表 `[]` | `zip` 返回的是**一次性生成器/迭代器**，消耗后不可重复使用。 |
