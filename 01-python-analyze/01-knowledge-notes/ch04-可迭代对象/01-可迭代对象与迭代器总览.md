> [!TIP]
> **30秒速记卡**
> - **可迭代对象 (Iterable)**：实现 `__iter__()`，能被 `for` 循环遍历（如列表、元组、字典、集合、字符串、range）。
> - **迭代器 (Iterator)**：同时实现 `__iter__()` 和 `__next__()`，**惰性求值**，单向产生，不持有所有元素，**不支持下标、切片与 `len()`**（如 `iter()` 返回的对象、生成器）。
> - **range 对象**：惰性序列但**不是迭代器**（没实现 `__next__()`）；支持下标索引和 `len()` 计算。
> - **可哈希铁律**：用于字典键或集合元素，对象及其**所有子元素必须均不可变**。包含列表的元组绝对不可哈希。

## 一、核心概念与三者边界

| 概念 | 底层魔法方法 | 内存与访问特点 | 典型代表 |
| :--- | :--- | :--- | :--- |
| **可迭代对象 (Iterable)** | `__iter__()` | 能返回一个迭代器，可用 `for...in` 遍历。 | `list`, `tuple`, `dict`, `set`, `str`, `range` |
| **迭代器 (Iterator)** | `__iter__()` + `__next__()` | **惰性求值**，每次调用 `next()` 生成一个值；不支持随机访问与下标；不存所有数据，不能用 `len()`。 | `iter(list)`, 生成器表达式, `map`, `filter`, `zip` |
| **容器对象 (Container)** | `__contains__()` 等 | 任意时刻在内存中**驻留并持有全部实际元素**。 | `list`, `tuple`, `str`, `dict`, `set` |

### 特殊角色：`range` 对象
- **为什么省内存？** 它只记录 `start`, `stop`, `step` 三个数值，不预先在内存实例化每一个元素。
- **为什么不是迭代器？** 没有实现 `__next__()` 方法，不能直接用 `next(r)`。
- **支持的操作**：支持索引（如 `r[2]`）、切片以及 `len(r)`。

## 三、字典键与集合元素：可哈希性判定准则

字典的 `Key` 和集合的元素要求必须是**可哈希（Hashable）**的。

### 判定心智模型：纯净不可变
- **与内部类型是否混杂无关**：`(1, 'hello', 3.14)` 内部混杂了整数、字符串、浮点数，但全是不可变类型，**完全可哈希**。
- **与嵌套层次无关，但任何子元素不能有可变对象**：
  - `(1, 2, (3, 4))` 👉 **可哈希**（内部纯元组与数字）
  - `(1, 2, [3, 4])` 👉 **不可哈希**（抛出 `TypeError: unhashable type: 'list'`）

## 四、易错避坑表

| 错误代码写法 | 报错原因 | 正确姿势 |
| :--- | :--- | :--- |
| `next(range(5))` | `TypeError: 'range' object is not an iterator` | `next(iter(range(5)))` 或使用 `for` 循环 |
| `it = iter([1, 2]); it[0]` | `TypeError: 'list_iterator' object is not subscriptable` | 迭代器只能通过 `next(it)` 单向逐个获取 |
| `d = {(1, [2]): 'val'}` | `TypeError: unhashable type: 'list'` | 元组内不得包含列表/字典等可变容器 |
