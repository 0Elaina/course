> [!TIP]
> **30秒速记卡**
> - **切片读取 `lst[start:stop:step]`**：左闭右开 `[start, stop)`；`step` 为负则逆向遍历；经典逆序为 `lst[::-1]`。
> - **越界宽容机制**：单下标访问越界抛 `IndexError`；**切片操作永远不报错**，越界部分自动截断（超出全空返回 `[]`）。
> - **切片赋值（原地修改）**：
>   - **连续切片（`step=1`）**：长度完全自由！支持将局部替换为更多或更少元素，甚至清空（`lst[1:3] = []` 等同于删除）。
>   - **跨步切片（`step!=1`）**：长度必须严格相等！右侧元素个数与切片坑位不一致直接抛 `ValueError`。
> - **整列表刷新 `lst[:] = []`**：保留原列表的内存地址，清空内部所有内容（与 `lst = []` 改变地址截然不同）。

## 一、切片读取与步长规则

### 1. 基础语法与符号含义
- `lst[start:stop]`：提取从 `start` 到 `stop - 1` 的元素，默认 `step=1`。
- `lst[::2]`：从头到尾隔一个取一个（提取偶数索引元素）。
- `lst[::-1]`：全列表反转（生成新列表，原列表不变）。

### 2. 越界行为对比
```python
a = [10, 20, 30]

# 单一下标访问：严格检查边界
print(a[10])     # ❌ IndexError: list index out of range

# 切片访问：优雅截断容错
print(a[1:100])  # ✅ [20, 30]（超出部分自动忽略）
print(a[10:20])  # ✅ []（完全不在区间内直接返回空列表）
```

## 二、切片赋值：对内存结构直接做手术

切片赋值是 Python 列表最具特色的就地修改机制：

| 切片类型 | 代码示范 | 左右长度要求 | 运行结果与影响 |
| :--- | :--- | :--- | :--- |
| **连续切片替换** | `a[1:3] = [8, 9, 10, 11]` | **完全自由**（可长可短） | 列表中间被撑大，自动向后推移剩余元素 |
| **连续切片删除** | `a[1:3] = []` | 自由（赋予空序列） | 等价于 `del a[1:3]`，列表自动收缩 |
| **连续切片插入** | `a[1:1] = [99]` | 自由 | 在索引 1 处原地插入元素 99，原位置元素后移 |
| **跨步切片赋值** | `a[::2] = [10, 20, 30]` | **必须严格一致** | 精确替换指定间隔坑位；数量不匹报 `ValueError` |

## 三、进阶场景：`lst[:]` 的内存意义

```python
x = [1, 2, 3]
y = x

# 场景 A：重新绑定变量 (开新房)
x = []
print(y)  # 依然是 [1, 2, 3] (y 仍指向原内存，x 指向了新空列表)

# 场景 B：切片清空 (拆旧房内部)
x = [1, 2, 3]
y = x
x[:] = []
print(y)  # 变成了 []！(因为 x 和 y 共享的原内存内容被原地清空)
```

## 四、易错避坑表

| 错误代码 / 误区 | 产生的后果 | 避坑指引 |
| :--- | :--- | :--- |
| `a = [1, 2, 3, 4]; a[::2] = [10]` | `ValueError: attempt to assign sequence of size 1 to extended slice of size 2` | 跨步切片赋值时，等号右侧元素的个数必须与被选中的索引坑位数完全一致。 |
| `a[1:3] = 99` | `TypeError: can only assign an iterable` | 切片赋值右侧必须是**可迭代对象**，不能是单个数值；需写成 `a[1:3] = [99]`。 |
| 误用 `lst[::-1]` 期望原列表被翻转 | 原列表毫发无损 | 切片读取仅返回新对象，若要原地翻转原列表，请使用 `lst.reverse()`。 |
