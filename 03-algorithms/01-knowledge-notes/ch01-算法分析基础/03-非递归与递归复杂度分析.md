# 03 非递归与递归复杂度分析

> **⚡ 30 秒速记**
> - **程序步规则**：循环头自身执行 $n + 1$ 次（最后一次判断跳出），简单语句与 return 各算 1 步。
> - **平均时间期望模型**：$A(n) = \sum_{I} P(I) \cdot T(n, I)$，命中概率均摊于各位置，未命中则付出全量扫描代价。
> - **空间复杂度核心**：**递归算法空间开销 = 系统调用栈最大深度**（二分递归为 $O(\log n)$，斐波那契单链最深为 $O(n)$）。
> - **主定理判定口诀**：比较 $\log_b a$ 与 $d$（大于 $\implies \Theta(n^{\log_b a})$，等于 $\implies \Theta(n^d \log n)$，小于 $\implies \Theta(n^d)$）。

---

## 一、是什么（一句话定义）
复杂度分析是通过对代码中基本运算与系统资源消耗进行数学建模，计算非递归程序步求和或求解递归递推方程闭式解，从而确定算法时间和空间开销的方法。

---

## 二、为什么这样设计
循环和递归是程序运行时间最主要的消耗点。掌握程序步统计、期望模型、主定理以及系统栈开销，能够让开发者在动笔编码前准确预估算法在大规模数据与极端场景下的性能和崩溃风险。

---

## 三、关键方法与核心模型

### 1. 程序步 (Program Step) 精确度量
程序步是语法或语义上有独立意义的执行段，其执行时间与规模无关。
- **循环头自身步数**：`for (int i = 0; i < n; i++)` 会判断 $n + 1$ 次，故循环头自身计 **$n + 1$ 步**！
- **课件经典案例 `Sum` 累加步数推导**：
  ```cpp
  float Sum(float list[], const int n) {
      float tempsum = 0.0;          // 赋值：1 步
      for (int i = 0; i < n; i++) { // 循环头自身：n + 1 步
          tempsum += list[i];       // 循环体内赋值：n 步
      }
      return tempsum;               // return 语句：1 步
  }
  ```
  $$\text{Total Steps} = 1 + (n + 1) + n + 1 = \mathbf{2n + 3}$$

### 2. 最好、最坏与平均时间复杂度模型
设输入规模为 $n$，$I$ 为具体输入实例，$T(n, I)$ 为该实例下的执行步数：
- **最好情况 $B(n) = \min_{I} T(n, I)$**
- **最坏情况 $W(n) = \max_{I} T(n, I)$**（工程兜底红线）
- **平均情况期望模型**：
  $$A(n) = \sum_{I \in D_n} P(I) \cdot T(n, I)$$
  - *例题（无序数组顺序查找）*：目标存在概率为 $p$（在 $n$ 个位置等概率分布，各为 $\frac{p}{n}$），不存在概率为 $1 - p$（需扫描 $n$ 次）：
    $$A(n) = \sum_{i=1}^n \left(\frac{p}{n} \cdot i\right) + (1 - p)n = \frac{p(n+1)}{2} + (1 - p)n$$
    若 $p=0.8$，则 $A(n) = 0.4(n+1) + 0.2n = \mathbf{0.6n + 0.4}$。

### 3. 空间复杂度深度拆解：固定空间 vs 递归系统栈深度
- **固定空间 (Fixed Space)**：代码区、简单临时变量，恒为 $O(1)$。
- **可变空间 (Variable Space)**：
  - 显式堆内存：`new`、`vector` 等容器开辟的内存。
  - **系统调用栈深度 (Call Stack)**：每次递归调用压入一个栈帧。
    - **递归二分查找**：每次折半，最大栈深度为 $\log_2 n \implies$ 空间复杂度 **$O(\log n)$**。
    - **斐波那契递归 `fib(n)`**：虽分支很多，但栈帧随返回而弹出，同一时刻最深调用链为 $n \implies$ 空间复杂度 **$O(n)$**。

### 4. 递归方程秒杀神器——主定理 (Master Theorem)
针对形如 $T(n) = a T(n / b) + f(n)$（其中 $a \ge 1, b > 1$ 为常数，$f(n) = \Theta(n^d)$）：

| 判别条件 | 谁占主导 | 最终紧确复杂度 | 典型算法示例 |
| :--- | :--- | :--- | :--- |
| **$\log_b a > d$** | 叶子分裂开销主导 | $\Theta(n^{\log_b a})$ | Karatsuba 大整数乘法 $T(n)=3T(n/2)+n \implies \Theta(n^{\log_2 3})$ |
| **$\log_b a = d$** | 各层合并开销均等 | $\Theta(n^d \log n)$ | 归并排序 $T(n)=2T(n/2)+n \implies \Theta(n \log n)$ <br> 二分查找 $T(n)=T(n/2)+1 \implies \Theta(\log n)$ |
| **$\log_b a < d$** | 根节点/合并开销主导 | $\Theta(n^d)$ | $T(n)=2T(n/2)+n^2 \implies \Theta(n^2)$ |

## 四、易错点与混淆辨析

| 典型陷阱 | 错误直觉 | 正确推导与避坑法则 |
| :--- | :--- | :--- |
| **倍增循环内层求和** | `for(i=1; i<=n; i*=2)`<br>`  for(j=1; j<=i; j++)` 误判为 $O(n \log n)$ | **实际为 $O(n)$**。内层运算量呈几何倍增：$1 + 2 + 4 + \dots + n = 2n - 1$。最高阶项由最后一轮 $n$ 统领，前面所有轮次总和不超过 $2n$。 |
| **主定理常数项指数 $d$** | $T(n)=T(n/2)+1$ 误将 $d$ 认作 1 | **$f(n)=1=n^0 \implies d=0$**。此时 $\log_2 1 = 0 = d \implies \Theta(n^0 \log n) = \Theta(\log n)$。 |
| **递归调用栈空间混淆** | 认为没有动态申请内存就是 $O(1)$ 空间 | **错误**。未分配堆内存但只要发生递归，栈空间深度即为空间复杂度。 |
