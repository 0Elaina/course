# 02 渐进符号体系与阶数分析

> **⚡ 30 秒速记**
> - **三大符号**：$O$（渐进上界，$\le$）、$\Omega$（渐进下界，$\ge$）、$\Theta$（紧确界/同阶，$\approx$）。
> - **终极利器：极限判别法**：求 $L = \lim_{n \to \infty} \frac{f(n)}{g(n)}$。若 $L = 0 \implies O$ 且 $o$；若 $L = c \implies \Theta$（亦满足 $O$）；若 $L = \infty \implies \Omega$。
> - **欧几里德 GCD 对数本质**：余数必定满足 $c < \frac{n}{2}$，首步取模直接将大数限制在 $\min(m, n)$ 内，复杂度为 $O(\log(\min(m, n)))$。

---

## 一、是什么（一句话定义）
渐进符号是用数学极限语言描述当问题输入规模 $n \to \infty$ 时，算法所需时间或空间资源增长特性的形式化表示法。

---

## 二、为什么这样设计
真实运行秒数受机器 CPU、编译器优化和常量因素扰动。渐进分析通过忽略低阶项和常数系数，直接抓住算法性能的本质数量级，实现客观可比的“事前分析”。

---

## 三、关键数学定义与核心工具

### 1. 三大核心渐进符号的严格数学定义

| 符号 | 中文名称 | 数学形式化定义（$\exists c, n_0 > 0, \forall n \ge n_0$） | 几何与直观含义 |
| :--- | :--- | :--- | :--- |
| **$O(g(n))$** | **渐进上界** | $f(n) \le c \cdot g(n)$ | 增长速度**不超过** $g(n)$（类似“$\le$”） |
| **$\Omega(g(n))$** | **渐进下界** | $f(n) \ge c \cdot g(n)$ | 增长速度**至少为** $g(n)$（类似“$\ge$”） |
| **$\Theta(g(n))$** | **渐进紧确界** | $c_1 g(n) \le f(n) \le c_2 g(n)$ | 增长速度**与 $g(n)$ 同阶**（类似“$=$”） |

> 📌 **同阶等价判定定理**：
> $$f(n) = \Theta(g(n)) \iff f(n) = O(g(n)) \text{ 且 } f(n) = \Omega(g(n))$$

### 2. 极限判别法（做题与分析核心实战法则）
计算比值极限 $L = \lim_{n \to \infty} \frac{f(n)}{g(n)}$：
- **$L = 0$**：$f(n)$ 远慢于 $g(n) \implies f(n) = O(g(n))$（严格小 $o(g(n))$）。
- **$L = c \in (0, \infty)$**：$f(n)$ 与 $g(n)$ 同阶 $\implies f(n) = \Theta(g(n))$（必然同时属于 $O(g(n))$ 和 $\Omega(g(n))$）。
- **$L = +\infty$**：$f(n)$ 远快于 $g(n) \implies f(n) \neq O(g(n))$，而是 $f(n) = \Omega(g(n))$。
- **两大求极限妙招**：
  1. **洛必达法则**：遇到 $\frac{\log n}{n^k}$ 时上下求导。
  2. **取对数法**：遇到庞大幂次（如 $n^{\log n}$ 与 $2^{\sqrt{n}}$）时，两边取 $\ln$ 对比指数增长率。

### 3. 阶数大小黄金天梯（从低到高）
$$O(1) < O(\log \log n) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 4. 经典算法演进案例：求最大公约数 (GCD)
- **连续整数检测法（暴力枚举）**：从 $\min(m, n)$ 向下减 1 逐个尝试，最坏复杂度为 **$O(\min(m, n))$**。
- **欧几里德辗转相除法 (Euclidean Algorithm)**：
  ```cpp
  int gcd(int a, int b) {
      return b == 0 ? a : gcd(b, a % b);
  }
  ```
  - **为什么复杂度是对数阶 $O(\log(\min(m, n)))$？**
    1. **余数折半定理**：对于 $n \ge m$，计算余数 $c = n \bmod m$ 时必有 **$c < \frac{n}{2}$**！
       - 若 $m \le \frac{n}{2}$：由余数定义 $c < m \le \frac{n}{2}$ 成立。
       - 若 $m > \frac{n}{2}$：商必为 1，余数 $c = n - m < n - \frac{n}{2} = \frac{n}{2}$ 成立。
    2. **首步截断机制（为什么取决于 $\min(m, n)$）**：
       - 无论被除数有多大（如 $10^{100}$），做完第 1 次取模后，余数立即掉落到 $\min(m, n)$ 范围以内。
       - 后续折半衰减完全由小数决定，因此至多只需要 $2 \log_2(\min(m, n))$ 步！

## 四、易错点与混淆辨析

| 混淆点 / 考题陷阱 | 正确认知 |
| :--- | :--- |
| **大 $O$ 必须是最紧的上界吗？** | **不是！** 大 $O$ 仅要求上界成立，例如 $f(n)=3n^2+5 \implies f(n)=O(n^2)$ 成立，同时 $f(n)=O(n^3)$、$f(n)=O(2^n)$ 均**合法且成立（True）**。只有 $\Theta$ 才要求同阶。 |
| **指数放缩陷阱** | 若 $f(n) = O(g(n))$，则 $2^{f(n)} = O(2^{g(n)})$ **不成立**！反例：$2n = O(n)$，但 $2^{2n} = 4^n \neq O(2^n)$。 |
| **对数底数的影响** | 根据换底公式 $\log_a n = \frac{\log_b n}{\log_b a} = \Theta(\log_b n)$，所有常数底数的对数都同阶，统一记作 $O(\log n)$。 |
