## ⚡ 30 秒公式与口诀速查卡（CheatSheet）

### 1. 阶数大小黄金序列
$$O(1) < O(\log \log n) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 2. 主定理 (Master Theorem) 判定口诀
针对递推方程 $T(n) = a T(n / b) + n^d$：
1. 计算叶子指数 $\log_b a$ 并与合并指数 $d$ 对比；
2. **$\log_b a > d$** $\implies T(n) = \Theta(n^{\log_b a})$（叶子主导）
3. **$\log_b a = d$** $\implies T(n) = \Theta(n^d \log n)$（均衡）
4. **$\log_b a < d$** $\implies T(n) = \Theta(n^d)$（合并主导）

### 3. 并查集复杂度
- **同时开启加权合并 + 路径压缩**：$m$ 次操作均摊时间复杂度为 $O(m \cdot \alpha(n))$（几乎为严格常数 $O(1)$）。

## ⚠️ 高频易错避坑速查表

| 常见陷阱 | 错误直觉 | 正确认知与避坑法则 |
| :--- | :--- | :--- |
| **大 $O$ 紧确性** | 认为 $3n^2 = O(n^3)$ 是错的 | **成立（True）**。大 $O$ 仅代表上界（$\le$），不要求紧确；只有 $\Theta$ 才要求同阶。 |
| **倍增内层累加循环** | 外层 $\log n$ 轮，内层执行 $i$ 次 $\implies O(n \log n)$ | **实际为 $O(n)$**。各轮内层执行次数为 $1+2+4+\dots+n = 2n-1$，等比数列和被最后一项主导。 |
| **主定理常数项** | 当 $f(n)=1$ 时误当成 $d=1$ | **$f(n)=1=n^0 \implies d=0$**。例如二分查找 $T(n)=T(n/2)+1 \implies \log_2 1 = 0 = d \implies \Theta(\log n)$。 |
| **算法 vs 程序** | 操作系统主循环是合法算法 | **不是**。操作系统死循环不满足“有穷性”，是程序而非算法。 |
