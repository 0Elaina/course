## ⚡ 30 秒公式与口诀速查卡（CheatSheet）

### 1. 阶数大小黄金天梯
$$O(1) < O(\log \log n) < O(\log n) < O(\sqrt{n}) < O(n) < O(n \log n) < O(n^2) < O(n^3) < O(2^n) < O(n!) < O(n^n)$$

### 2. 极限判别法判断大 $O$ 与同阶
计算 $L = \lim_{n \to \infty} \frac{f(n)}{g(n)}$：
- **$L = 0$** $\implies f(n) = O(g(n))$ 且 $f(n) = o(g(n))$（$f$ 增长远慢于 $g$）
- **$L = c \in (0, \infty)$** $\implies f(n) = \Theta(g(n))$（同阶，必有 $f(n)=O(g(n))$）
- **$L = \infty$** $\implies f(n) = \Omega(g(n))$ 且 $f(n) \neq O(g(n))$（$f$ 增长远快于 $g$）

### 3. 主定理 (Master Theorem) 判定口诀
针对递推方程 $T(n) = a T(n / b) + n^d$：
1. 计算叶子指数 $\log_b a$ 并与合并指数 $d$ 对比；
2. **$\log_b a > d$** $\implies T(n) = \Theta(n^{\log_b a})$（叶子主导）
3. **$\log_b a = d$** $\implies T(n) = \Theta(n^d \log n)$（均衡）
4. **$\log_b a < d$** $\implies T(n) = \Theta(n^d)$（合并主导）

### 4. 空间复杂度铁律
- **递归算法额外空间开销 = 系统调用栈最大深度**！
  - 递归二分查找：区间折半 $\implies$ 空间深度为 $O(\log n)$；
  - 斐波那契递归 `fib(n)`：最深单链深度 $\implies$ 空间开销为 $O(n)$。

### 5. 布隆过滤器核心铁律
- **零漏报（无假阴性）**：判定为“不存在”则 **100% 绝对不存在**！
- **有误报（有假阳性）**：判定为“存在”时只是**可能存在**（哈希碰撞导致）。
- **局限性**：位数组天然不支持普通删除；支持删除需改用计数布隆过滤器 (Counting Bloom Filter)。

## ⚠️ 高频易错避坑速查表

| 常见陷阱 | 错误直觉 | 正确认知与避坑法则 |
| :--- | :--- | :--- |
| **大 $O$ 紧确性** | 认为 $3n^2 = O(n^3)$ 是错的 | **成立（True）**。大 $O$ 仅代表上界（$\le$），不要求紧确；只有 $\Theta$ 才要求同阶。 |
| **程序步统计** | `for (i=0; i<n; i++)` 循环头算 $n$ 步 | **实际为 $n + 1$ 步**。最后一次判断为 false 退出也要消耗 1 步。 |
| **欧几里德 GCD 复杂度** | 认为除以大数耗时很长 | **实际为 $O(\log(\min(m, n)))$**。余数严格满足 $c < n/2$，且第 1 步取模直接将大数拉低至较小数以下。 |
| **假阳性 vs 假阴性** | 弄不清哪个是“误报”，哪个是“漏报” | **假阳性 = 误报**（实际没有却报有）；**假阴性 = 漏报**（实际有却漏判）。布隆过滤器绝对无漏报。 |
| **递归调用栈空间** | 只要没写 `new`/`malloc` 空间就是 $O(1)$ | **错误**。函数递归时系统栈帧堆叠，最大调用深度直接决定空间复杂度。 |
