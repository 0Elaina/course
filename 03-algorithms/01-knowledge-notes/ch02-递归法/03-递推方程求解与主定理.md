# 03 递推方程求解与主定理

> **⚡ 30 秒速记**
> - **三大求解武器**：
>   1. **替换方法**：先猜解，后用数学归纳法证明。注意初始基底不强制从 $n=1$ 开始，大 $O$ 关注充分大 $n$。
>   2. **迭代法/递归树**：机械展开求和。递归树有三大格局：根节点主导（等比递减，看根）、各层均衡（看每层 $\times$ 树高）、叶子主导（等比激增，看叶子）。
>   3. **公式法（主定理）**：比较叶子指数 $\log_b a$ 与合并项 $f(n)$。
> - **主定理三大 Case**：针对 $T(n) = a T(n/b) + f(n)$：
>   - Case 1：$f(n)$ 多项式小于叶子 $n^{\log_b a} \implies T(n) = \Theta(n^{\log_b a})$
>   - Case 2：$f(n)$ 与叶子同阶 $\implies T(n) = \Theta(n^{\log_b a} \log n)$
>   - Case 3：$f(n)$ 多项式大于叶子 $\implies T(n) = \Theta(f(n))$
> - **必考失效反例**：$T(n) = 2T(n/2) + n \log n$，比值差仅为对数因子 $\log n$，不满足 Case 3 的“多项式大于”（差值达到 $n^\varepsilon$），不可套用主定理！

---

## 一、替换方法（先猜后证）

1. **核心思路**：依据直觉或经验猜测渐近上界 $T(n) \le c \cdot g(n)$，再将假设代入原递推式中进行不等式放缩。
2. **避坑关键**：若 $n=1$ 时出现数学边界矛盾（如 $c \cdot 1 \cdot \log 1 = 0$），归纳法可合法选择 $n=2, 3$ 作为基底，完全符合大 $O$ 定义。

---

## 二、递归树求和的三大经典格局

| 格局 | 各层代价变化 | 算力大头位置 | 最终时间复杂度 | 课件代表方程 |
| :--- | :--- | :--- | :--- | :--- |
| **根节点主导** | 等比快速衰减（公比 $< 1$） | 顶层根节点 | $O(f(n))$ | $T(n) = 2T(n/2) + n^2 \implies O(n^2)$ |
| **各层均衡** | 每一层总代价恒定 | 各层均摊 | $O(f(n) \log n)$ | $T(n) = 2T(n/2) + n \implies O(n \log n)$ |
| **叶子节点主导** | 等比成倍暴涨（公比 $> 1$） | 底层叶子节点 | $O(n^{\log_b a})$ | $T(n) = 3T(n/2) + kn \implies O(n^{1.59})$ |

## 三、公式法（主定理 Master Theorem）速查

通用方程：
$$T(n) = a T(n/b) + f(n)$$

1. **先求叶子指数**：$p = \log_b a$，叶子总开销为 $n^p$；
2. **将 $f(n)$ 与 $n^p$ 对比**：
   - 若 $f(n)$ 明显慢于 $n^p$（落后 $n^\varepsilon$ 级）$\implies T(n) = \Theta(n^p)$（Case 1）
   - 若 $f(n)$ 与 $n^p$ 同阶 $\implies T(n) = \Theta(n^p \log n)$（Case 2）
   - 若 $f(n)$ 明显快于 $n^p$（超出 $n^\varepsilon$ 级且正则）$\implies T(n) = \Theta(f(n))$（Case 3）

### 经典失效反例剖析
- 方程：$T(n) = 2T(n/2) + n \log n$
- $a=2, b=2 \implies n^{\log_2 2} = n$
- 对比：$f(n) / n = \log n$
- **失效根因**：比值 $\log n$ 增长慢于任何 $n^\varepsilon$（$\forall \varepsilon > 0$），它既不满足 Case 2（不是同阶常数倍），也不满足 Case 3（达不到多项式级差距），落入主定理盲区，必须改用迭代法求解。
