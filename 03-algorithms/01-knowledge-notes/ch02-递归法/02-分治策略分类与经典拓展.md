# 02 分治策略分类与经典拓展

> **⚡ 30 秒速记**
> - **两大策略**：
>   - **减而治之 (Decrease & Conquer)**：线性递归，规模减 1，栈深 $O(n)$，超大规模（如 20000）容易爆栈。
>   - **分而治之 (Divide & Conquer)**：非线性递归，折半二分，栈深仅 $O(\log n)$，稳健不溢出。
> - **线段树 22 字金诀**：“不交直接扔，全包直接用；部分重叠先下推，左右递归再合并”。建树 $O(n)$，单次区间查询 $O(\log n)$。
> - **双递归与 Ackerman**：自变量内层嵌套调用函数自身。其逆函数 $\alpha(n)$ 增长极慢，在所有现实正整数内常年满足 $\alpha(n) \le 4$，并查集复杂度 $O(\alpha(n))$ 近似常数时间。

---

## 一、分治策略两大形态对比

| 维度 | 减而治之 (线性递归) | 分而治之 (非线性递归) |
| :--- | :--- | :--- |
| **规模缩减** | 线性递减：$n \to n-1$ | 比例递减：$n \to n/2$ |
| **子问题分支** | 单分支单链 | 2 个或多个分支树状 |
| **最大调用栈深度** | $O(n)$（单链堆叠，极易栈溢出） | $O(\log n)$（树高极浅，安全） |
| **典型案例** | 线性数组求和、阶乘 | 归并排序、二分数组求和、线段树 |

## 二、线段树（Segment Tree）的分治模型

### 1. 业务痛点
对无序数组频繁进行区间和查询，朴素遍历查询 $m$ 次耗时 $O(mn)$。线段树将单次查询降为 $O(\log n)$。

### 2. 四大基础操作复杂度
- 建树 (`build`)：$O(n)$
- 单点修改：$O(\log n)$
- 区间查询：$O(\log n)$
- 区间修改：$O(\log n)$

### 3. 递归建树代码（Java）
```java
public static Segment buildst(int[] ary, int l, int r) {
    if (l == r) return new Segment(l, r, ary[l], null, null);
    int mid = (l + r) / 2;
    Segment left = buildst(ary, l, mid);
    Segment right = buildst(ary, mid + 1, r);
    return new Segment(l, r, left.sum + right.sum, left, right);
}
```

## 三、双递归函数与逆阿克曼函数 $\alpha(n)$

1. **双递归定义**：函数的参数包含对函数自身的调用，如 $A(n, m) = A(A(n-1, m), m-1)$。
2. **运算升级阶梯**：
   - $m=0 \implies n+2$（加法级）
   - $m=1 \implies 2n$（乘法级）
   - $m=2 \implies 2^n$（指数级）
   - $m=3 \implies 2^{2^{\dots^2}}$（指数塔级）
3. **逆阿克曼函数 $\alpha(n)$**：
   - 定义：$\alpha(n) = \min\{k \mid A(k) \ge n\}$
   - 增长速度远慢于 $\log n$：$O(1) < O(\alpha(n)) < O(\log \log n) < O(\log n)$。
   - 现实数据范围内恒有 $\alpha(n) \le 4$。
