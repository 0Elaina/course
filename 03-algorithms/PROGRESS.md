## 薄弱点
| 知识点 | 问题描述 |
|--------|---------|
| 递归调用栈空间深度判定 | 已通过数组求和减治(O(n))与分治(O(log n))对比牢固掌握“空间看树高、时间看节点数”心智模型 |
| 概率期望模型中的事件拆解 | 在计算平均时间时，容易将单一的“未命中完整事件”概率与均摊的“命中子事件”概率混淆（如多除以 n） |
| 渐进符号反例推导 | 容易凭直觉推论，对指数放缩（如 2^{f(n)} = O(2^{g(n)}) 不成立）等深层反例敏感度不足 |
| 并查集与布隆过滤器实战 | 初次接触，仅建立概念模型与架构认知，尚不具备独立编码、状态演变及排错能力 |
| 递归栈物理溢出边界 | 容易忽略系统物理栈大小限制，误以为有终止条件就绝不崩溃（超深线性递归仍会爆栈） |
| 逆阿克曼函数阶数比较 | 容易将阿克曼函数的超快增长与逆函数 α(n) 的极慢增长混淆，需牢记 α(n) 增长远慢于 log n，常年 ≤ 4 |
| 主定理参数代入与叶子指数 | 容易凭直觉把 4T(n/2) 等不同参数惯性当成归并排序的 2T(n/2)，需先求 log_b a 算出叶子函数 n^{log_b a} |
