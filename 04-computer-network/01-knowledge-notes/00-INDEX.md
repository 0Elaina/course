## ⚡ 30秒核心速查卡 (CheatSheet)

| 核心考点 | 表达式 / 口诀 / 要点 | 适用场景 |
| :--- | :--- | :--- |
| **两两直连线路** | $\frac{N(N - 1)}{2} \approx \frac{1}{2}N^2$ | 无交换机时电话两两直连所需线路对数 |
| **发送时延** | $t = \frac{\text{数据长度 } L}{\text{发送速率 } R}$ | 网卡推数据上信道（受网卡带宽决定） |
| **传播时延** | $t = \frac{\text{物理距离 } D}{\text{电磁波速率 } V}$ | 信号在线路上传播（光纤中约 $2 \times 10^8\text{ m/s}$） |
| **有效数据率** | $\frac{\text{数据量 } L}{t_{\text{发送}} + \text{RTT}}$ | 考虑等待对端 ACK 确认时的实际端到端吞吐率 |
| **时延带宽积** | $\text{传播时延} \times \text{带宽}$ | 链路管道中容纳的比特容量 |
| **利用率与时延** | $D = \frac{D_0}{1 - U}$ | 当利用率 $U \to 1$ 时时延趋向无穷大 |
| **协议三要素** | **语法**（结构）、**语义**（含义/动作）、**同步**（时序） | 协议定义与选择题判断 |
| **层间关系口诀** | **“协议水平对等，服务垂直供给，SAP 门牌接口”** | 概念辨析与体系结构简答 |
| **TCP三次握手本质** | 验证双方“能发能收”4项能力的**最小工程代价** | 面试与期末八股高频必考 |

## 🚨 易错避坑表

| 常见易错题型 | 坑点描述 | 避坑秘籍 |
| :--- | :--- | :--- |
| **“高速链路比特跑得更快”** | 误以为高带宽能缩短传播时延。在 1000 km 光纤中，1 B 数据的传播时延恒为 5 ms；带宽哪怕从 1 Mbps 狂飙到 1 Gbps，总时延也仅从 5.008 ms 变成 5.000008 ms。提高带宽**只能缩短发送时延**。 | 必须拆分为发送时延和传播时延分别计算！ |
| **“两军问题能靠多次握手解决”** | 不可靠信道上不存在能 100% 保证共识的协议。握手四次、五次同样无法消除最终丢包风险。 | 牢记三次握手是工程最佳折中，非理论完美消除不可靠。 |
| **“RFC 文档等于网络标准”** | 互联网草案（6个月失效）不是 RFC；RFC 还包含信息/实验文档；只有升级为 **STD** 的才是正式标准。 | 牢记“所有标准是 RFC，并非所有 RFC 都是标准”。 |
| **“存储单位与网络速率换算”** | 误把网速 100Mbps 当作每秒下载 100MB。 | $1\text{ Byte} = 8\text{ bit}$，通信进位为 1000 进制（$10^3$），存储为 1024 进制（$2^{10}$）。 |
| **“协议 vs 服务”** | 协议是通信双方对等实体在水平方向的共同约定；服务是本系统内部下层向上层在垂直方向提供的接口支持。 | 牢记“协议水平，服务垂直”。 |
