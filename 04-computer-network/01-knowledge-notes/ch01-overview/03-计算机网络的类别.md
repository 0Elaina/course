## 计算机网络的核心定义：互连与自治

计算机网络是由若干互相连接的、**自治（Autonomous）**的计算机集合：
- **互连（Interconnected）**：节点间具备数据通路，能够按协议规范收发数据。
- **自治（Autonomous）**：每台终端拥有独立的 CPU、内存与操作系统，不存在一台大型主机对其他终端的绝对主从控制。

## 网络的多维度分类体系

### 1. 按地理覆盖范围分类（核心基石）

```
+-------------------------------------------------------------------------+
| 【广域网 WAN】 (几十 ~ 几千公里，跨省跨国主干网，采用路由器互连)             |
|   +-------------------------------------------------------------------+ |
|   | 【城域网 MAN】 (5 ~ 50 公里，覆盖一个城市/行政区)                  | |
|   |   +-------------------------------------------------------------+ | |
|   |   | 【局域网 LAN】 (几米 ~ 1 公里，校园网/机房，采用交换机/以太网) | | |
|   |   |   +-------------------------------------------------------+ | | |
|   |   |   | 【个人区域网 PAN】 (约 10 米，蓝牙/WiFi热点个人设备)   | | | |
|   |   |   +-------------------------------------------------------+ | | |
|   |   +-------------------------------------------------------------+ | |
|   +-------------------------------------------------------------------+ |
+-------------------------------------------------------------------------+
```

| 类别缩写 | 英文全称 | 中文名称 | 覆盖距离 | 典型应用与技术 |
| :--- | :--- | :--- | :--- | :--- |
| **WAN** | Wide Area Network | 广域网 | 几十 ~ 几千 km | 国家骨干网、海底光缆、BGP 路由 |
| **MAN** | Metropolitan Area Network | 城域网 | 5 ~ 50 km | 城市电子政务专网、城域以太网 |
| **LAN** | Local Area Network | 局域网 | 1 km 左右 | 校园网、写字楼 WiFi、以太网交换机 |
| **PAN** | Personal Area Network | 个人区域网 | 10 m 左右 | 蓝牙耳机、智能手环、无线键鼠 |

---

### 2. 按使用者与接入性质分类

- **公用网（Public Network）**：电信/联通/移动等运营商出资兴建，任何公众或企业按章缴费即可接入。
- **专用网（Private Network）**：军队、电网调度、铁路信号系统等为了高安全隔离与绝对可靠性独立建设，不对公众开放。
- **接入网 AN（Access Network）**：指用户端设备（家庭光猫、校园交换机）到本地 ISP 第一个核心边缘路由器之间的物理通信链路，行业俗称“**最后一公里（Last Mile）**”。

## 易混淆考点与避坑

1. **终端主从 vs 自治网络**：早期的“大型机 + 哑终端”系统不属于计算机网络，因为哑终端不具备独立计算操作系统，没有“自治”属性。
2. **局域网与广域网的技术差异**：局域网（LAN）通常误码率极低、广播成本低，重在以太网帧交换；广域网（WAN）拓扑复杂、线路昂贵，重在分组路由与拥塞控制。
