# 01-互联网概述与标准化（1.1 / 1.2 / 1.4 节）

> **30秒速记卡**：
> - **互联网两大基本特征**：**连通性 (Connectivity)**（远程如直连，便捷经济互通信息） + **资源共享 (Sharing)**（信息/软件/硬件共享，服务提供基础）。
> - **三网融合**：电信网络、有线电视网络与计算机网络融合，以计算机网络为核心。
> - **概念辨析**：`internet`（互连网，通用名词，任意协议互联） vs `Internet`（因特网，专有名词，全球最大 TCP/IP 网络）。
> - **演进三阶段**：ARPANET（1983 年采用 TCP/IP 为因特网诞生年） $\to$ NSFNET（主干/地区/校园三级） $\to$ 多级 ISP（商业化）。
> - **多层 ISP 与 IXP**：主干 ISP $\to$ 地区 ISP $\to$ 本地 ISP；IXP（互联网交换点）允许同级 ISP 直连对等交换流量，降低时延与转接费。
> - **RFC 标准两阶段**：互联网草案（有效期 6 个月，非 RFC） $\to$ 建议标准（赋予 RFC 编号） $\to$ 互联网标准（成熟检验，赋予 STD 编号）。*注：所有标准都是 RFC，并非所有 RFC 都是标准*。

## 核心概念辨析：网络、互连网与因特网

- **计算机网络（Network）**：由若干**节点（Node，如计算机、交换机）**和连接这些节点的**链路（Link）**组成的独立自治系统。
- **互连网（internet，小写 i）**：通用名词。指由多个计算机网络通过路由器连接而成的“网络的网络”，通信协议不受限制。
- **因特网（Internet，大写 I）**：专有名词。指当前全球最大、基于 **TCP/IP 协议族** 互联的开放网络。

## 拓扑演进：多层 ISP 结构与 IXP 交换点

### 1. 多层 ISP（互联网服务提供者）的分级协作
为了支撑全球亿万级终端接入，互联网形成了树状分级结构：

```
                    +------------------------------------+
                    |        主干 ISP (Tier 1 ISP)        |
                    |    (覆盖全国/全球的高速骨干网)      |
                    +---------+----------------+---------+
                              |                |
                    +---------+----+      +----+---------+
                    |  地区 ISP A  |<====>|  地区 ISP B  |  <--- 通过 IXP 对等互连 (Peering)
                    +---------+----+ (IXP)+----+---------+
                              |                |
                    +---------+----+      +----+---------+
                    |  本地 ISP    |      |  本地 ISP    |
                    +---------+----+      +----+---------+
                              |                |
                       [家庭/校园用户]     [企业/服务器]
```

- **主干 ISP**：国家/洲际骨干网运营者，拥有极高带宽线路。
- **地区 ISP**：连接主干与本地区域的中层服务商。
- **本地 ISP**：面向家庭、高校与企业提供宽带接入的“最后一级运营商”。

### 2. IXP（互联网交换点）的核心价值
- **解决痛点**：若无 IXP，同城两家地区 ISP 通信必须绕道国家主干 ISP，不仅延迟大幅增加，还需向上支付昂贵的流量结算费。
- **直连对等（Peering）**：IXP 允许不同运营商在物理交换点处直接交换本地流量，实现**低时延、零/低转接成本**。

## 发展历程与标准化规范

### 1. 互联网演进的三个阶段
| 阶段 | 时期 | 演进特征与标志 |
| :--- | :--- | :--- |
| **ARPANET 阶段** | 1969 ~ 1983 年 | 单网络向互连网探索。**1983 年 TCP/IP 成为标准协议，标志因特网正式诞生**。 |
| **NSFNET 三级阶段** | 1985 ~ 1993 年 | 由美国国家科学基金会主导的非商业网：**主干网 $\to$ 地区网 $\to$ 校园网/企业网**。 |
| **多级 ISP 商业化** | 1993 年 ~ 至今 | 政府退出运营，商业 ISP 投资主导，形成全球多级 ISP + IXP 体系。 |

### 2. RFC 文档与成为正式标准的必经之路（RFC 6410 规范）
所有的因特网技术规范均以 **RFC（Request for Comments）** 形式公开：

```
[ 技术讨论起草 ]                [ 正式标准第一阶段 ]                   [ 正式标准第二阶段 ]
互联网草案 (Internet Draft)  =====> 建议标准 (Proposed Standard) =====> 互联网标准 (Internet Standard)
(非 RFC 文档，有效期 6 个月)             (正式分配 RFC 编号并广泛应用)            (成熟检验稳定，分配 STD 编号)
```

## 🇨🇳 中国互联网发展速查（1.4 节考前 3 行速记）

> [!TIP]
> 期末选择/填空高频背景考点，极简记忆关键年份与缩写即可，无需背诵商业人物历史：

1. **里程碑接入（1994 年 4 月 20 日）**：我国用 **64 kbit/s** 专线正式全功能连入国际互联网，中国被国际正式承认为接入互联网的国家。
2. **五大公用计算机网络**：
   - 中国电信 **CHINANET**、中国联通 **UNINET**、中国移动 **CMNET**；
   - 中国教育和科研计算机网 **CERNET**（我国首个 IPv4 主干网；2004 年建成纯 IPv6 的下一代 **CERNET2** 主干网）；
   - 中国科学技术网 **CSTNET**。
3. **统计发布机构**：**CNNIC**（中国互联网络信息中心），每年两次发布我国互联网统计报告。

## 易错点与避坑指南

| 易错点 | 常见坑点描述 | 避坑秘籍 |
| :--- | :--- | :--- |
| **两大基本特征** | 混淆互联网的特征与功能 | 牢记两大基本特征是“**连通性**”与“**资源共享**”，填空常客。 |
| **大小写混淆** | 误以为 internet 和 Internet 完全是一个东西 | 小写 `internet` 泛指任意路由器互联网络；大写 `Internet` 专指全球最大 TCP/IP 因特网。 |
| **RFC 等同于标准** | 误以为“只要有 RFC 编号就是因特网标准” | 所有的正式标准都是 RFC，但 RFC 中包含了大量信息类、实验类及非标准草案，只有晋升为 **STD** 的才是正式标准。 |
| **草案的有效性** | 误以为草案能长期生效或具备标准效力 | 互联网草案只是标准前期的讨论稿，**不是 RFC**，最长保存期仅为 6 个月。 |
